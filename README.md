# Indias-State-by-State-admission-and-placement-data-Analysis
This project analyzes higher education data in India from 2013 to 2021.
The dataset includes three major domains: Engineering, Pharmacy, and Management.
The project studies the growth and decline of educational institutions over the years.
It examines the number of new institutions established and institutions closed each year.
The analysis focuses on student intake capacity and enrollment trends.
It evaluates gender-wise enrollment patterns, including both male and female students.
The project investigates faculty strength and its relationship with student enrollment.
It analyzes student performance through pass-out statistics and placement records.
Data analytics techniques such as data cleaning, exploratory data analysis (EDA), and visualization are used to generate insights.
The findings help educational institutions, researchers, and policymakers make informed decisions regarding higher education planning and development.
